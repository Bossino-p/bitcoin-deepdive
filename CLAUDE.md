# Bitcoin Deep Dive — project context

## What this is
A single-page Bitcoin deep dive built from a true bitcoiner's perspective.
No fluff, no "for dummies" framing, no calling it "crypto".

## Stack
- Plain HTML + CSS + vanilla JS (no framework)
- Single page, section-based layout
- Orange and black palette

## Sections (in order)
1. Hero — manifesto
2. Origin story
3. Timeline — key incidents
4. How it works — transactions, UTXO, mining
5. Tokenomics — supply schedule, halvings
6. Technical deep dives — Taproot, SegWit, Lightning (accordion)
7. Risk matrix — quantum, AI, 51%, fee cliff, etc.
8. What Bitcoin represents — the closer
